# This or That

Pick between pairs of artworks; a small taste model learns you in 25 picks, then guesses your next 10.
Static site + one Vercel Function (`api/session.js`) that stores each session anonymously in a private Vercel Blob store.

Generated from the research repo (`app/vercel/build_site.py`); edit there and rebuild instead of editing here.
Artworks: LAPIS dataset (Maerten et al. 2025), CC BY-NC 4.0, non-commercial use only.

Download the collected sessions: see `scripts/pull-sessions.mjs`.
